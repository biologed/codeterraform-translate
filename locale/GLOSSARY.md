# Глоссарий перевода Code: Terraform

Строк много (12 484), переводятся они партиями и в разное время, поэтому
термины легко разъезжаются: в одном месте «аванпост», в другом «форпост».
Здесь зафиксированы решения, принятые при переводе. Если меняете термин —
меняйте и здесь, и уже переведённые строки (поиском по `locale_ru.json`).

## Названия машин

Встречаются в подсказках задолго до группы `machines`, поэтому фиксируем
сразу: Pioneer → «Пионер», rover → «ровер», drone → «дрон»,
Crop Automator → «агроавтомат», Grow Lamp → «фитолампа»,
Sprinkler → «разбрызгиватель», Dispenser → «раздатчик»,
Lightning Rod → «громоотвод».

## Правила

- **Подстановки `{name}`, `{count}` не трогаем** — ни переводить, ни
  переставлять внутрь других слов. Их проверяет `merge_translation.py`.
- **Имена функций API остаются английскими**: `boot()`, `activate_power()`.
  Переводим описание вокруг них, а не сам вызов — иначе подсказка будет
  расходиться с кодом, который пишет игрок.
- **Формы множественного числа** (`ключ.one` / `ключ.other`) выбираются по
  английским правилам: `.one` для 1, `.other` для всего остального. Поэтому
  в `.other` пишем формулировку, верную для любого числа:
  «Найдено сохранений: {count}», а не «{count} сохранения».
- **Разметка сохраняется**: `**жирный**`, обратные кавычки вокруг кода,
  переносы строк `\n`, стрелки и значки (`←`, `⚠`, `🎧`) — как в оригинале.
- Короткие подписи кнопок держим короткими: место в интерфейсе рассчитано
  на английский текст, русский обычно длиннее на 20–30%.

## Как добавлять партии

```
python Translator/tools/merge_translation.py locale_ru.json batch_XX.json --check code-terraform_strings/catalog.json
```

Скрипт проверит ключи и подстановки, вольёт перевод в `locale_ru.json` и
покажет общий прогресс. В игре изменения применяются по F6 (или при
следующем запуске).
