РУСИФИКАТОР CODE: TERRAFORM
===========================

КАК УСТАНОВИТЬ

1. Скопируйте все файлы из этого архива в папку с игрой - туда, где лежит
   code-terraform.exe. Найти её можно так: в Steam правой кнопкой по игре ->
   "Управление" -> "Посмотреть локальные файлы".
2. Запускайте игру двойным кликом по "Запустить с переводом.bat" вместо
   code-terraform.exe.

Всё. Строки, которые ещё не переведены, игра покажет по-английски.

Если хотите, чтобы обычная кнопка "Играть" в Steam тоже запускала игру с
переводом: правой кнопкой по игре -> "Свойства" -> "Параметры запуска" и
вставьте туда (свой путь, %command% оставить как есть):

   "ПОЛНЫЙ\ПУТЬ\К\TranslatorLauncher.exe" --launch-cmdline "ПОЛНЫЙ\ПУТЬ\К\Translator.dll" %command%


ПОЧЕМУ АНТИВИРУС МОЖЕТ РУГАТЬСЯ

Коротко: перевод работает изнутри игры, а попасть внутрь чужой программы
можно только тем же способом, которым это делают вредоносные программы. Сам
приём и вызывает тревогу, а не то, что делает мод.

Что именно происходит:
  * TranslatorLauncher.exe запускает игру и загружает в её процесс
    Translator.dll (это называется "внедрение DLL");
  * Translator.dll перехватывает момент создания окна браузера, в котором
    игра рисует интерфейс, и подменяет английские строки на русские.

Оба действия - обычная техника игровых модов, но по формальным признакам
они не отличаются от вредоносных. Плюс файлы не подписаны сертификатом
(он стоит денег и требует юридического лица), поэтому Windows дополнительно
показывает "Неизвестный издатель".

ЧЕГО МОД НЕ ДЕЛАЕТ: не выходит в интернет, не трогает файлы вне папки игры,
не собирает никаких данных, не изменяет системные настройки и не остаётся в
системе после выхода из игры. Всё, что он пишет - это translator_log.txt
рядом с собой.

КАК УБЕДИТЬСЯ, ЧТО ФАЙЛЫ ТЕ САМЫЕ

1. Сверьте SHA-256 файлов из архива со значениями в SHA256SUMS.txt. В
   PowerShell: Get-FileHash Translator.dll -Algorithm SHA256
2. Исходный код открыт целиком, а релизные файлы собираются на серверах
   GitHub по сценарию, который лежит в том же репозитории. К каждой сборке
   прикладывается подпись происхождения, её можно проверить командой
   gh attestation verify Translator.dll -R <репозиторий>
3. Ничто не мешает собрать мод самостоятельно - инструкция в README.

ЕСЛИ АНТИВИРУС ВСЁ РАВНО УДАЛЯЕТ ФАЙЛЫ

Добавьте папку с игрой в исключения антивируса. И, пожалуйста, отправьте
файл как ложное срабатывание - это помогает всем остальным:
  * Microsoft Defender: https://www.microsoft.com/en-us/wdsi/filesubmission
  * другие антивирусы принимают такие заявки на своих сайтах.


УДАЛЕНИЕ

Удалите из папки игры: Translator.dll, TranslatorLauncher.exe,
locale_ru.json, "Запустить с переводом.bat", translator_log.txt. Игра
останется в точности такой, какой была: файлы игры мод не изменяет.
